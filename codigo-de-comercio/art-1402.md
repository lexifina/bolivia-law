# Artículo 1402
Art. 1.402º.- (Otras formas de crédito) La relación contractual entre el Banco y ordenante, cuando no se sustente precisamente en el pago efectivo del Banco a favor del beneficiario, puede tener como base el "crédito de firma", "crédito de aceptación", "aval" o "crédito de fianza o garantía", que se regulará por las normas pertinentes de este Código.
